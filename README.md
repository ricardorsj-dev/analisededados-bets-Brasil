# 📊 Análise do Crescimento das Bets no Brasil e Impactos Sociais

## 📌 Visão Geral

Este projeto tem como objetivo analisar a evolução do mercado de apostas esportivas (bets) no Brasil, correlacionando seu crescimento com fatores sociais e econômicos, como:

* Aumento do número de apostadores
* Crescimento do faturamento do setor
* Impacto por classe social
* Possível relação com o aumento de casos de ludopatia

A análise combina técnicas de **data analysis, visualização de dados e machine learning**, gerando insights relevantes sobre um dos mercados que mais crescem no país.

---

## 🎯 Objetivos

* Entender o crescimento do mercado de apostas no Brasil
* Identificar padrões no comportamento dos usuários
* Analisar o impacto social por classe econômica
* Explorar possíveis correlações com problemas como ludopatia
* Projetar tendências futuras utilizando regressão linear

---

## 📊 Análises Realizadas

### 🔝 Top 10 Bets no Brasil

Identificação das principais casas de apostas com base no faturamento estimado.

### 📈 Crescimento do Mercado

Evolução do faturamento ao longo dos anos, demonstrando expansão acelerada do setor.

### 👥 Crescimento de Usuários

Análise do aumento no número de apostadores ativos.

### 📊 Crescimento Percentual

Variação ano a ano, evidenciando momentos de explosão no mercado.

### 🔗 Relação Usuários x Receita

Correlação direta entre aumento de usuários e crescimento do faturamento.

### 🤖 Projeção com Machine Learning

Uso de regressão linear para prever o crescimento do mercado até 2028.

### 🏷️ Análise por Classe Social

Identificação de maior vulnerabilidade em classes sociais mais baixas.

### ⚠️ Bets x Ludopatia

Análise comparativa entre crescimento do setor e aumento de casos de vício em jogos.

---

## 📌 Principais Insights

* O crescimento das bets é **exponencial**, não linear
* Existe forte correlação entre número de usuários e faturamento
* Classes sociais mais baixas apresentam **maior exposição ao risco**
* Há indícios de crescimento conjunto entre o mercado e problemas sociais
